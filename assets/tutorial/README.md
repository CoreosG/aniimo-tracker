# Tutorial examples

Prepared with the built-in image_gen tool from player-supplied screenshots, then stripped of ancillary PNG metadata. Originals are not included. These examples must never be used as OCR regression fixtures.

Prompt set:
- Inventory: retain the complete inventory UI and top-right balance; remove UID, usernames, chat, external overlays, FPS and window-border slivers; no annotations or new personal information.
- Loot: retain the original loot result and 431719 valuation; remove UID, account identifiers, chat, external overlays and FPS; no invented labels.
- Points: retain the positive +370 and original points UI; remove UID, account identifiers, FPS and the two player-specific achievement labels/badges on the left; replace removed elements with matching background.

The green focus rectangles are drawn by the tutorial UI. Game artwork belongs to Pawprint Studio / FunPlus.
