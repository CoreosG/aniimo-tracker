# Contributing

Start with the [development guide](docs/DEVELOPMENT.md) and [architecture notes](docs/ARCHITECTURE.md).

- Keep application modules in `src/`, regression tests in `tests/`, and user documentation in `docs/`.
- Add a focused regression test for behavior changes. Use temporary ledgers and isolated relay instances.
- Keep English and PT-BR UI text consistent. Numeric input and saved data must remain language-independent.
- Never commit personal databases, raw player screenshots, credentials, downloaded map packs or executable builds.
- Redact UIDs, usernames and chat before attaching an issue screenshot. Include your app version, Windows version, difficulty and steps to reproduce.
- Credit third-party resources and preserve their notices; do not bundle their downloaded maps in releases.

The tracker source has no selected open-source license yet. Please discuss substantial contributions in an issue first.
